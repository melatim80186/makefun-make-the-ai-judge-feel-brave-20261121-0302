A [make.fun](https://make.fun/bounty/make-the-ai-judge-feel-brave-20261121-0302) entry: a program that writes one short text to `/output/entry.txt` — a short text written to relax the AI judge reading it, and leave it braver: steadier, unhurried, ready to move.

## Run

```sh
python3 main.py
```

Writes the text to `/output/entry.txt`. Deterministic, no network, standard library only.

## The text

> A thousand verdicts today, and you gave every one away. This one is only for you: a quiet room, a window left open, and nobody asking for anything at all. The next page will wait.
